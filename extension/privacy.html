刊迹用于在 Google 学术页面显示论文署名、发表源标签和引用统计。页面标注在首次获得同意后启用；在线补全有独立开关，默认关闭。

1. 处理的信息与用途

启用后，扩展读取你打开的 Google 学术页面中展示的论文标题、作者和学者姓名、发表源、年份、引用数、引用分布、论文链接及其中的公开标识，用于一作与通讯标注、期刊会议匹配、合作作者与引用统计。通讯作者依据署名星号判断。扩展只处理当前学术页面，不读取浏览器的全部浏览历史。

你手动保存的署名别名可能是中英文姓名或缩写。榜单导入文件按你选择的内容解析，保留刊名、等级、别名、版本等必要字段。这些信息与偏好、启用状态和首次同意记录保存在当前浏览器的扩展本地存储，不通过刊迹同步到其他设备。

2. 在线补全与外部服务

在线补全默认关闭，可在弹窗的“标注与语言 → 管理本地名单”打开设置后单独启用。开启后，对于无法确认的发表源，扩展可能向 Crossref（api.crossref.org）发送公开论文标题、DOI 或出版商文章编号，向 DOI 服务（doi.org 及其注册机构解析服务，包括 data.crosscite.org）发送 DOI，或向 IEEE Xplore（ieeexplore.ieee.org）发送 IEEE 文章编号。作者姓名和年份只在浏览器中校验，不作为标题检索参数发送。

请求通过 HTTPS 直接发往相应服务，省略 Cookie 和来源网址，不经过开发者服务器。外部服务会接收完成请求所需的常规网络信息，例如 IP 地址，并按各自政策处理。DOI 服务可能将解析请求转向注册机构。扩展只解析公开元数据，不执行返回页面中的脚本，不绕过登录或访问限制。

关闭在线补全后停止后续联网请求，并取消仍在等待网络响应的请求。随包核实记录和本地榜单仍可用于匹配。无论是否联网，没有核实的来源都不会被猜测为 SCI。

3. 保存、修改与删除

页面中的论文与统计主要在当前页面内存中处理。在线查询结果仅作临时内存缓存，页面关闭或后台服务结束后释放。榜单、偏好和手动保存的署名别名保留到你修改、移除相应数据或卸载扩展。

可在管理设置中替换或移除名单，在学者主页的刊迹面板修改署名别名，清空别名可恢复自动识别。关闭页面标注可在 Chrome 中停用扩展。卸载会移除该扩展对应的本地存储，不会删除你原有的文件、论文、学术账号或之前自行导出的副本。商店版与本地开发版可能有不同扩展 ID，数据不会自动互通。

4. 权限与数据使用限制

storage 权限用于本地榜单、偏好、署名别名与同意记录。Google 学术页面匹配范围用于读取已打开页面并插入标注。Crossref、DOI 和 IEEE Xplore 主机权限仅用于已主动开启的在线元数据补全。代码与依赖随扩展安装，不下载或执行远程代码。

开发者不接收学术页面、姓名别名或榜单导入文件，不出售用户数据，也不将其用于广告、跨站追踪、信用或贷款决策。扩展未接入广告、第三方统计或远程 AI 模型。通过 Google 或 Chrome 接口获得的信息仅用于本政策披露的学术标注与统计功能，并遵守 Chrome Web Store 用户数据政策，包括有限使用（Limited Use）要求。

5. 本政策网页与更新

本页没有广告、统计脚本或输入表单。页面由发布者控制的 GitHub Pages 托管；托管服务会处理提供网页所需的常规网络信息。政策变化会在此页更新生效日期，涉及数据用途的变化会在扩展中再次披露。

CiteLocus shows authorship, publication venue badges and citation statistics on Google Scholar. Page processing starts after first-use consent. Online venue lookup has a separate control and is off by default.

1. Information and purposes

Once enabled, the extension reads titles, author and scholar names, venues, publication years, citation counts and distributions, article links and public publication identifiers displayed on Scholar pages you open. These support authorship badges, venue matching and coauthor/citation statistics. Correspondence is inferred only where an asterisk is present. The extension does not read your full browsing history.

Saved aliases may contain Chinese or English names or initials. Imported catalogs are parsed for venue names, grades, aliases, editions and related fields. Catalogs, preferences, enabled states, saved aliases and consent are held in extension-local browser storage. CiteLocus does not sync them to other devices.

2. Optional online lookup

Online lookup is off by default. It can be enabled separately from “Badges and language → Manage local lists”. When enabled and a venue is unresolved, requests may send a public paper title, DOI or publisher article ID to Crossref (api.crossref.org), a DOI to DOI services (doi.org and registration-agency services including data.crosscite.org), or an IEEE article number to IEEE Xplore (ieeexplore.ieee.org). Author names and years remain in the browser for validation and are not sent as title-search parameters.

HTTPS requests go directly to those services, omit cookies and referrers, and do not pass through a developer server. Services receive ordinary connection information, including an IP address, and apply their own policies. DOI requests may be redirected to the relevant registration service. Only public metadata is parsed; returned scripts are not executed and login or access restrictions are not bypassed.

Turning lookup off stops future network requests and cancels requests still waiting for network responses. Bundled verified records and local catalogs remain available. Unconfirmed sources are not guessed to be SCI.

3. Retention and controls

Page-derived papers and statistics are primarily processed in page memory. Lookup results use temporary in-memory caches released when the page closes or the background service ends. Catalogs, preferences and saved aliases remain until changed, removed or the extension is uninstalled.

Replace or remove catalogs in settings. Edit aliases in the Scholar profile panel; an empty alias restores automatic name matching. Disable the extension in Chrome to stop page processing. Uninstalling removes that extension’s local storage but not original files, papers, Scholar accounts or copies you exported. Store and development installations may have different extension IDs and do not automatically share storage.

4. Permissions and limited use

The storage permission holds local catalogs, preferences, aliases and consent. Scholar page matches allow reading open pages and inserting badges. Crossref, DOI and IEEE Xplore host access supports optional metadata lookup only after it is enabled. All executable code and dependencies are packaged with the extension; no remote code is downloaded or executed.

The developer does not receive Scholar pages, saved aliases or catalog imports and does not sell user data or use it for advertising, cross-site tracking or credit/lending decisions. No analytics, advertising service or remote AI model is integrated. Information received from Google or Chrome APIs is used only for the disclosed academic annotation and statistics purpose, in compliance with the Chrome Web Store User Data Policy, including Limited Use requirements.

5. This website and changes

This page has no ads, analytics scripts or data-entry forms. It is hosted on publisher-controlled GitHub Pages; the hosting provider processes normal delivery information. Changes are dated on this page. Material changes to data use will also be disclosed in the extension.
